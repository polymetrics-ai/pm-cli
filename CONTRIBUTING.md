# Contributing

This repository is public so that people can read it. It does not accept outside contributions at this time:

- Only collaborators can open issues and pull requests.
- Continuous integration runs only for branches that collaborators push to this repository. Pull requests from forks never run on our runners.

To report a security problem, follow [SECURITY.md](SECURITY.md).
